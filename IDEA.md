# My app

**Domain:** Washington trail finder: a searchable list of hiking trails around Washington State (regions, trails, and hiker trip reports).

**User story:** As a hiker in Seattle, I need to find trails that fit my distance, elevation gain, and difficulty limits, so that I can pick a hike for this weekend that I can actually finish.

**What the user types or picks:** a region (e.g. Snoqualmie Pass, Mount Rainier, Olympic Peninsula, North Cascades), a maximum distance in miles, a maximum elevation gain in feet, and a difficulty (easy / moderate / hard), plus an optional "dog-friendly" checkbox. The page shows the matching trails sorted by rating, with each trail's most recent trip report.
